## 1. FPGA & Digital Logic Foundations

**FPGA**:
A reconfigurable integrated circuit containing programmable Look-Up Tables, flip-flops, block RAM, and routing switches that implement custom digital hardware circuits directly in silicon.
_Avoid_: Microcontroller, emulator

**LUT**:
A Look-Up Table—the basic combinational logic building block inside an FPGA (4-input LUT4 on Gowin GW2A/GW2AR devices) that implements any Boolean truth table over its inputs.
_Avoid_: Software lookup array

**Active-Low**:
A signal convention where the asserted or "on" physical state corresponds to logic `0` (ground, 0 V) rather than logic `1` (3.3 V), such as the Tang Nano 20K's six onboard LEDs.
_Avoid_: Negative logic (when referring to pin polarity)

**Non-Blocking Assignment**:
The Verilog `<=` operator used inside clocked `always @(posedge clk)` blocks so all right-hand sides are sampled before any left-hand-side register updates on the clock edge.
_Avoid_: Sequential assignment

**Ripple-Carry Adder**:
A multi-bit adder built by chaining 1-bit Full Adders so each stage's `carry_out` ripples into the next stage's `carry_in` from least-significant to most-significant bit.
_Avoid_: Parallel carry-lookahead adder

**Multiplexer**:
A combinational selector circuit (commonly written `sel ? a : b` in Verilog) that routes one of multiple input buses onto an output wire based on a control signal.
_Avoid_: Software if/else branch

**Carry Chain**:
Dedicated hardwired routing and arithmetic cells (`ALU` primitives on Gowin FPGAs) built into logic slices to propagate carries across multi-bit adders faster than general-purpose LUTs.
_Avoid_: General LUT cascade

**D Flip-Flop**:
A clocked 1-bit storage element (`DFF` / `DFFRE` on Gowin) that snapshots its `d` input only on a rising clock edge (`posedge clk`) and holds `q` steady between edges.
_Avoid_: Transparent latch

**Enable Pulse**:
A single-clock-cycle control signal (`tick` or `step`) generated by a timer on the global clock so slower logic updates periodically without creating divided clock trees.
_Avoid_: Divided clock

**Finite State Machine**:
A sequential hardware controller (`FSM`) pairing a `state` flip-flop register with `localparam` state constants and a `case (state)` next-state/output decoder.
_Avoid_: Thread state machine

## 2. Toolchain & Verification Pipeline

**Synthesis**:
The compilation stage (`yosys`) that translates Verilog RTL into a netlist of target FPGA primitives such as LUTs, carry chains, and flip-flops.
_Avoid_: Compiling (without specifying hardware synthesis)

**Place and Route**:
The physical layout stage (`nextpnr-himbaechel`) that assigns synthesized logic cells to specific silicon locations on the FPGA die and wires interconnecting signal paths to meet pin and timing constraints.
_Avoid_: Linking

**Constraint File**:
A `.cst` configuration file mapping logical Verilog top-level port names to physical FPGA package pin numbers, I/O voltage standards (`LVCMOS33`), pull resistors, and drive strengths.
_Avoid_: Config file

**Bitstream**:
The packed binary configuration image (`.fs`) produced by `gowin_pack` and loaded onto the FPGA over USB by `openFPGALoader` to configure its internal hardware routing and LUTs.
_Avoid_: Firmware binary

**Testbench**:
A non-synthesizable Verilog harness module (`_tb.v`) run in simulation (`iverilog` + `vvp`) that drives input waveforms, checks assertions (`$fatal`), and dumps signal histories to a `.vcd` file.
_Avoid_: Unit test script

## 3. Video Architecture, Clocking & Memory

**Raster Scan**:
The progressive line-by-line, left-to-right, top-to-bottom pixel traversal order (`x` inner counter, `y` outer counter) used to drive VGA and HDMI displays.
_Avoid_: Frame buffer blit

**Blanking Interval**:
The non-visible horizontal and vertical periods (front porch, sync pulse, and back porch) surrounding the active picture during which RGB outputs must remain black (`0, 0, 0`).
_Avoid_: Screen margin

**Pixel Clock**:
The steady clock frequency (`25.2` MHz for 640×480@60 Hz) at which each pixel tick (`800 × 525 × 60`) advances across the display.
_Avoid_: CPU clock

**PLL**:
A Phase-Locked Loop (`rPLL` on Gowin FPGAs)—an analogue/mixed-signal hard block that multiplies and divides a crystal input clock to synthesise new locked frequencies such as `126` MHz.
_Avoid_: Software timer

**Clock Domain**:
A group of flip-flops clocked by the same clock source; signals crossing between asynchronous domains (`27` MHz ↔ `25.2` MHz) require synchronisers to prevent metastability.
_Avoid_: Thread pool

**TMDS**:
Transition-Minimized Differential Signaling—the DVI/HDMI 8b/10b line coding algorithm that cuts bit transitions (`XOR`/`XNOR`) and preserves DC balance using a running disparity counter.
_Avoid_: Packet compression

**Running Disparity**:
The cumulative signed imbalance `(ones - zeros)` tracked across transmitted TMDS symbols (`bias`) so bit 9 can invert upcoming words to keep the cable DC-neutral.
_Avoid_: Parity bit

**Differential Pair**:
Two matched physical signal wires (`_p` and `_n`, driven by `TLVDS_OBUF`) carrying opposite polarities so the receiver cancels common-mode electrical noise.
_Avoid_: Single-ended bus

**Serializer**:
A dedicated high-speed hardware shift primitive (`OSER10` on Gowin) that latches a wide parallel word on the pixel clock (`25.2` MHz) and shifts bits out serially at DDR (`126` MHz = `252` Mbps).
_Avoid_: UART transmitter

**Frame Buffer**:
A region of dedicated video memory (`bitmap_mem` and `color_mem` in Lesson 8) scanned continuously by the raster engine to paint each pixel on screen.
_Avoid_: Screen cache

**Block RAM**:
Dedicated synchronous SRAM memory tiles (`SP` / `SPX9` primitives on Gowin FPGAs) inferred from Verilog arrays to store kilobytes of data without consuming general-purpose LUTs or flip-flops.
_Avoid_: Distributed register file

**Pipeline Latency**:
The one-or-more clock cycles required for a synchronous module (such as Block RAM) to output data after receiving an address, requiring matching register delays on parallel control signals.
_Avoid_: Propagation jitter

**Colour Clash**:
An artefact of attribute-cell graphics where all pixels inside a fixed tile (`8×8` pixels) share only two palette colours (**ink** and **paper**), preventing three independent colours inside one cell.
_Avoid_: Palette corruption

## 4. 6502 Architecture, Assembler & Bus

**Accumulator**:
The primary 8-bit arithmetic and logic register (`A`) inside the 6502 through which loads, additions, subtractions, and bitwise operations flow.
_Avoid_: General-purpose register file

**Program Counter**:
The 16-bit internal register (`PC`) holding the memory address of the next instruction or operand byte to be fetched by the CPU.
_Avoid_: Instruction pointer register (x86 terminology)

**Status Register**:
The 8-bit processor flags register (`P`, bit layout `N V - B D I Z C`) recording arithmetic conditions and control modes updated as instructions execute.
_Avoid_: Condition code stack

**Little-Endian**:
A multi-byte storage convention where the least-significant byte comes first at the lower address, encoding `` `$C002` `` as `02 C0` in 6502 machine code.
_Avoid_: Big-endian network byte order

**Addressing Mode**:
The rule specifying how an instruction interprets its operand bytes—such as Immediate (`#$01`), Absolute (`$8000`), or Implied (`CLC`).
_Avoid_: Instruction opcode family

**Relocation**:
The linker pass in `ld65` that replaces unresolved segment-relative placeholders (`rr rr` in `ca65` listings) with final physical addresses once segments are placed.
_Avoid_: Dynamic runtime linking

**Linker Configuration**:
A `memory.cfg` script defining physical `MEMORY` regions (`ZP`, `RAM`, `ROM`) and mapping assembly `SEGMENTS` (`CODE`, `RODATA`, `VECTORS`) into fixed address ranges.
_Avoid_: Makefile dependency script

**System Bus**:
The shared bundle of 16-bit `address`, unidirectional `data_in` / `data_out`, and `write` control wires connecting the CPU to RAM, ROM, and I/O devices.
_Avoid_: Internal tri-state bus

**Address Decoding**:
Combinational logic inspecting upper address bits (`address[15:14]`) to enable exactly one target region—RAM (`$0000`–`$7FFF`), I/O (`$8000`–`$BFFF`), or ROM (`$C000`–`$FFFF`).
_Avoid_: Dynamic memory paging

**Memory-Mapped I/O**:
Assigning hardware peripherals such as onboard LEDs to ordinary memory addresses (`$8000`) so standard `STA`/`LDA` instructions control hardware without dedicated I/O opcodes.
_Avoid_: Port-mapped I/O

**Reset Vector**:
The boot entry address (`$C000` hard-wired during Lesson 12, later read from `$FFFC`–`$FFFD`) where the CPU begins fetching after `reset`.
_Avoid_: Interrupt handler table

**Dead-Code Elimination**:
A synthesis optimisation in `yosys` that removes unreachable registers or entire Block RAM primitives (such as unwritten RAM in Lesson 12) whose outputs can never affect top-level ports.
_Avoid_: Runtime garbage collection
